# Генератор меню на основе описаний с использованием Llama 3.2

Дипломный проект: приложение для генерации клиентского интерфейса (меню) по текстовому описанию.

## Возможности
- Ввод произвольного описания меню на русском языке.
- Анализ с помощью локальной LLM (Llama 3.2 через Ollama).
- Автоматический подбор стилей, цветов, компоновки и дополнительных компонентов.
- Генерация HTML-страницы с меню и открытие в браузере.
- Логирование ответов модели для анализа.

## Установка
1. Установите Python 3.11+.
2. Установите зависимости: `pip install -r requirements.txt`
3. Установите [Ollama](https://ollama.com/) и загрузите модель:
   ollama pull llama3.2:3b
